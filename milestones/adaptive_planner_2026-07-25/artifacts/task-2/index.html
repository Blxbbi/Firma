Firma

Deterministisches Multi-Agenten-Execution-Framework für Softwareprojekte

Orchestriere autonome KI-Worker über ein strukturiertes Task-System mit strengen Zustandsmaschinen, reproduzierbaren Runs und durchgängiger Artefakt-Traceability.

Jetzt starten Architektur ansehen
Deterministisch · Reproduzierbar · Read-only Workers

Architektur

Strenge Zustandsmaschinen und spezialisierte Worker sorgen für vorhersagbare, nachvollziehbare Runs.

Researcher

Recherchiert Anforderungen, identifiziert Constraints und liefert evidenzbasierte Entscheidungsgrundlagen.

Planner

Erstellt aus Anforderungen eine schrittweise, priorisierte Ausführungsplanung mit klaren Abhängigkeiten.

Coder

Implementiert die geplanten Änderungen nach Spezifikation, beachtet Barrierefreiheit und Clean Code.

Reviewer

Prüft Code auf Korrektheit, Wartbarkeit, Sicherheit und Übereinstimmung mit der Spezifikation.

Guardian

Wahrt Integrität und Sicherheit: Prüft Vertrauensgrenzen, Berechtigungen und Audit-Trail-Konsistenz.

Orchestrator

Steuert den Gesamtablauf, validiert Zustandsübergänge und stellt die Einhaltung des definierten Workflows sicher.

Features & Stärken

Determinismus

Gleiche Eingaben erzeugen gleiche Ausgaben. Keine versteckten Zufallsfaktoren, keine nicht-reproduzierbaren Seiteneffekte.

Reproduzierbarkeit

Jeder Run ist wiederholbar und auditable. Änderungen an Tasks, Prompts oder State erzeugen nachvollziehbare Revisionen.

Read-only Workers

Worker lesen den State, schreiben ausschließlich Artefakte. Der State-Owner bleibt die Engine — kein Worker mutiert den globalen Zustand.

Artefakt-Tracking

Alle Ausgaben werden versioniert, referenziert und im Workflow weitergegeben. Keine verlorenen Dateien, keine undefinierten Abhängigkeiten.

Auditing

Vollständiger Audit-Trail mit Zeitstempeln, Events und Zustandsrevisionen. Nachvollziehbarkeit ist kein Feature, sondern Pflicht.

Einsatzzweck

Firma eignet sich für Teams, die komplexe Softwareprojekte mit KI-Workern orchestrieren wollen — ohne die Kontrolle über Abläufe, Qualität und Nachvollziehbarkeit abzugeben.

Typische Szenarien:

  • Automatisierte Implementierung von Spezifikationen
  • Strukturierte Code-Generierung mit integrierter Review
  • Reproduzierbare Research- und Planungs-Workflows
  • Audit-fähige AI-Assistenten in regulierten Umgebungen

Das Framework trennt Verantwortlichkeiten klar: Researcher, Planner, Coder und Reviewer arbeiten als spezialisierte Worker. Die Engine wacht über den State, validiert Übergänge und garantiert, dass kein Schritt übersprungen wird.

Installation & Start

In wenigen Schritten bereit für reproduzierbare, KI-gestützte Software-Workflows.

1

Repository klonen

git clone https://github.com/firma-engine/firma.git
2

Abhängigkeiten installieren

npm install
3

Engine starten

npm start
4

Ersten Run definieren

firma run ./examples/hello-world
