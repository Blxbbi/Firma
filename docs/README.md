# Docs-Übersicht

Diese README erklärt die Struktur des `docs/`-Ordners.

## Struktur

```
docs/
├── decisions/   # Chronologische Entscheidungen, Stände und Lessons Learned
├── guides/      # Betrieb, Tests, Start, Workflows und How-Tos
├── plans/       # Implementierungspläne und Phasenkonzepte
├── vision/      # Architektur, Strategie und Überblicksdokumente
├── meta/        # Projektstruktur, Migration und Prozessdokumentation
├── briefings/   # Kunden- und beraterorientierte Briefings
└── README.md    # Diese Datei
```

## Kurzbeschreibung

| Ordner | Inhalt |
|--------|--------|
| `decisions/` | Stände (`Stand DD.MM.YYYY.md`), Bewertungen, Architektur-Entscheidungen |
| `guides/` | Bedienungsanleitungen, Smoke-Tests, Seeding, Testing, Startup |
| `plans/` | Phase-Pläne (`Plan_PhaseX_*.md`, `PhaseX_*.md`) |
| `vision/` | Gesamtarchitektur, Workflows, Vision-Dokumente |
| `meta/` | Projekt-Layout, Prozesse, Migration |
| `briefings/` | Externe Briefings wie `Firma.md`, `Briefing_Berater_PiMesh.md` |

## Navigation

- Neu im Projekt? → `meta/PROJECT_LAYOUT.md`
- Architektur verstehen? → `vision/PiMesh_Architektur.md`
- Betrieb starten? → `guides/Startup.md`
- Letzte Entscheidungen? → `decisions/`
